# Amanzi Ordering System

Purified water ordering system for NWU Mafikeng campus.

## Overview
Amanzi Ordering System is a web-based application designed to simplify and streamline the process of ordering purified water at the North-West University (NWU) Mafikeng campus.

## Features
- Easy ordering of purified water
- User authentication and management
- Order tracking and status updates
- Admin dashboard for order processing

## Technologies Used
- JavaScript
- React
- Node.js
- Express.js
- MongoDB

## Getting Started
To run the Amanzi Ordering System locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Bheki0987/Amanzi-Ordering-System.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
